That spirit is still available. A personal site can be quiet, unfinished, and specific. It does not need to compete for attention or explain itself to an algorithm. It only needs to be a place you can point to.

Small is a feature

A page that loads quickly, has a clear link to the next page, and does not ask for anything in return is already a pleasant surprise. The limitations make the writing more deliberate and the experience more human.

Maybe the slow web is simply the web where we remember that a person made the page.
